# Commit C27: Cart Management UI

## Goal
Implement the interactive cart summary with line item management.

## User Stories (Traceability)
- **US-08**: Change Quantity (Numpad input)
- **US-09**: Price Override (Manual entry)

## Proposed Changes
- **Components**:
    - `PosCartPanel`: Connect to `usePosCart` hook. Render list of `CartLineItem`.
    - `CartLineItem`: Display product info, qty, price. Actions: Edit Qty, Price Override, Remove.
    - `NumPadDialog`: Reusable dialog for numeric input (Qty/Price).
- **Hooks**:
    - Update `usePosCart` to support `updateLine` (qty, price) and `removeLine`.
- **Feedback**:
    - Use `flash()` for success/error messages.

## Verification
- **Automated**:
    - Unit tests for `CartLineItem` rendering.
    - Integration tests for `usePosCart` actions.
- **Manual (Browser)**:
    1.  Add item to cart -> Verify appears in panel.
    2.  Click item Qty -> Change to 5 -> Verify total updates.
    3.  Click item Price -> Override to $1.00 -> Verify total updates.
    4.  Remove item -> Verify disappears.
